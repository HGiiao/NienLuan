TÍNH NĂNG CHÍNH — GIÁ REALTIME (SIGNALR)

📡 Luồng dữ liệu realtime qua SignalR

⚙️ PriceStreamService (Background)

Chạy nền mỗi ~30 giây, cập nhật giá mới trong DB
→ Broadcast qua Hub

⟶

🔌 PriceHub (WebSocket)

Server push giá mới đến tất cả client
đã Join theo tuyến cụ thể

⟶

🖥️ Frontend — usePriceStream Hook

Nhận giá mới → cập nhật UI realtime
Tự reconnect khi mất kết nối

JoinRoute(from, to) — chỉ nhận giá tuyến đang xem OnClosed → tự reconnect sau 5s Fallback: Polling 30s khi WebSocket lỗi

⚙️ Server-side

PriceStreamService là IHostedService — khởi động cùng app.
Mỗi 30s: randomize ±5% giá các chuyến bay trong 7 ngày tới → cập nhật DB.
Gửi event PriceUpdated tới group theo tuyến.

🖥️ Client-side

Hook usePriceStream() khởi tạo ConnectionOptions → gọi startStrategy().
Khi user vào trang so sánh giá: gọi joinRoute(from, to).
Sự kiện onPriceUpdate cập nhật state → UI refresh.

🛡️ Dự phòng

Nếu SignalR disconnect → tự chuyển sang polling mỗi 30s.
Khi kết nối lại → switch back sang WebSocket.
Ngăn memory leak bằng cleanup khi unmount component.
