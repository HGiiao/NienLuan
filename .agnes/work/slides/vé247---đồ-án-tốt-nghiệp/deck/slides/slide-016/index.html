TRANG ADMIN — QUẢN TRỊ HỆ THỐNG

📊 Dashboard Thống Kê

  • Tổng doanh thu (theo ngày/tháng/năm)
  • Số booking mới, số user mới
  • Biểu đồ doanh thu (Recharts)
  • Top 5 tuyến có nhiều booking nhất
  • Tỷ lệ booking thành công / hủy
  • Thống kê theo phương tiện

👥 Quản lý Người dùng

  • Danh sách users (bảng DataTable)
  • Xem chi tiết user, đổi vai trò Admin/User
  • Xóa user (xử lý cascade booking)
  • Tìm kiếm theo tên/email/số điện thoại
  • Phân trang + bộ lọc

✈️ Quản lý Chuyến bay / Tàu / Xe

  • CRUD: Thêm / Sửa / Xóa chuyến bay
  • CRUD: Thêm / Sửa / Xóa chuyến tàu
  • CRUD: Thêm / Sửa / Xóa chuyến xe khách
  • Nhập/xuất Excel (.xlsx) hàng loạt
  • Quản lý số chỗ, giờ bay, giá

🎫 Quản lý Booking & Promo

  • Xem tất cả booking, lọc theo trạng thái
  • Cập nhật trạng thái: Pending → Confirmed/Canceled
  • Xóa booking & xử lý hoàn tiền
  • Quản lý mã giảm giá (WELCOME10, SUMMER25...)
  • Quản lý gói VIP/Subscription

🔐 Phân quyền & Bảo mật

🔒 Chỉ admin mới truy cập được /admin/* routes
🔒 RequireAdminAttribute — kiểm tra role trên mỗi controller action
🔒 Password BCrypt, không lưu plain text
🔒 JWT token xác thực API requests
