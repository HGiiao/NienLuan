🖥️ Frontend → Vercel

GitHub push → Vercel tự build (Vite) → deploy tĩnh
Cài đặt env: VITE_API_URL = URL backend
VITE_CLERK_PUBLISHABLE_KEY

https://ve247-booking.vercel.app
CI/CD tự động HTTPS

⚙️ Backend → Azure App Service

dotnet publish → zip → az webapp deploy
Plan B1, Always On = true (giữ background service awake)
Connection string + CORS config trong App Settings

https://ve247-api.azurewebsites.net
Windows Plan B1 Always On .NET 10

🗄️ Database → Azure SQL

SQL Server Serverless trên Azure
Firewall mở cho dịch vụ Azure
Backup tự động, scaling linh hoạt

ve247-serverless-nguyen2.database.windows.net
Serverless Auto-pause Backup tự động

❌ Trước đây (Localhost)

Frontend chạy localhost:5173, backend localhost:5000, DB Azure SQL.
Không truy cập được từ ngoài. CORS bị lỗi. Không có domain thật.

✅ Sau khi deploy Production

Website truy cập được từ mọi nơi qua domain thật.
Frontend + Backend + DB đều chạy trên cloud. CI/CD tự động mỗi khi push code.

⚠️ Lưu ý quan trọng: Vercel chỉ chứa giao diện tĩnh. Nếu backend không truy cập được (DNS lỗi, Azure stopped), trang sẽ trống trơn — không có dữ liệu hiển thị. Đây là lỗi đã từng xảy ra và đã được khắc phục.
